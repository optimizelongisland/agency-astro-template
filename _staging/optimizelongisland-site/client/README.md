# Client record

What we know about this client and what was agreed. Agents read these before
working on the site, so keep them current.

| File | What it is |
|---|---|
| `brief.md` | The approved content brief: business facts, services, copy, testimonials, old URLs. The only source of facts for the site. Copy `brief.example.md` to start. |
| `design-direction.md` | The design direction written for this site (concept, tokens, type, page structure). Later changes should stay consistent with it. |

Nothing here is published on the website. Reference-site screenshots are kept
out of the repo in `.design-refs/`, because they are other people's material.
