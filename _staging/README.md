# Staging (temporary)

`optimizelongisland-site/` is the new Optimize Long Island website, built from
this template and parked here only until it has its own repository. It is a
complete, separate project: to work on it, copy the folder into its own
repository and run `npm install` there.

Nothing in this folder is part of the template. Remove `_staging/` from this
branch once the site has moved.

The site's keyword research, site plan and page briefs (`client/seo/` in the
working copy) are kept privately and are not in this public repository. The
brief here points to them; they move with the site into its own private
repository.
